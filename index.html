Private YouTube Video Transfer

Personal Cloud Video Backup

About This Application

Private YouTube Video Transfer is a personal backup utility intended to transfer video files from the owner's Microsoft OneDrive account to the owner's YouTube channel.

How It Works

The application uses authorized access to Microsoft OneDrive to retrieve selected video files and the YouTube Data API to upload them to YouTube with Private visibility.

Purpose

This application is intended for personal video backup and is not a public video sharing service.

Privacy

Videos are intended to remain Private on YouTube. Access credentials are not published on this website.
